# Мониторинг здоровья школьника (Android)

Приложение для сбора 11 анкет мониторинга здоровья школьников с обменом данными между родителями и учителем через файл, выгрузкой в **XLSX по официальным макетам** и **PDF**.

## Как это работает

**Родитель**: вход по коду приглашения класса → создаёт карточку ребёнка (три буквы ФИО + дата + пол, полные ФИО не хранятся) → заполняет 7 своих анкет (№4, 5, 6, 9, 10) и «детских» (№7, 8) с автосохранением и прогрессом → кнопка «Отправить учителю» упаковывает всё в JSON-файл и отправляет через любой мессенджер / почту.

**Сотрудник школы**: вход по логину и паролю → в кабинете «Загрузить данные родителя» → выбирает пришедший файл → все ответы родителя импортируются в базу класса. Классный руководитель заполняет №11, медработник — №1 и №2, физрук — №3, администратор — всё.

**Выгрузка**: одной кнопкой формируются 11 XLSX-файлов ровно в формате ваших макетов (лист «данные», строка 1 — коды полей, строка 2 — русские подписи, дальше по строке на ребёнка) + PDF на каждого ребёнка по каждой анкете.

**Администратор**: создаёт классы с кодами приглашений, добавляет аккаунты учителей с назначением ролей и классов, может сбросить все данные.

## Что уже есть

- Тёмная тема (следует настройке системы)
- Edge-to-edge (контент под системными панелями)
- Автосохранение форм — черновики сохраняются автоматически
- Валидация с диапазонами (числа, даты, обязательные поля)
- Прогресс-бары везде (по анкете, по классу, по ребёнку)
- Подтверждения при удалении
- Пустые состояния с подсказкой что делать
- Материал 3 с dynamic color (на Android 12+)

## Сборка через GitHub

1. Создайте пустой репозиторий на GitHub.
2. Залейте туда содержимое этой папки через `git`:
   ```bash
   git init
   git add -A
   git commit -m "Initial"
   git branch -M main
   git remote add origin https://github.com/ВАШ/REPO.git
   git push -u origin main
   ```
   Не тяните файлы в браузер — папка `.github` может потеряться.
3. Actions запустится автоматически. Через ~5–7 минут скачайте `HealthMonitor-debug-apk.zip` из **Actions → последний запуск → Artifacts**.
4. Распакуйте, установите APK на Android (Настройки → Безопасность → разрешить установку из неизвестных источников).

Минимальная поддерживаемая версия Android — 7.0 (API 24).

## Как расширить

- **Добавить/изменить вопросы в анкете**: правьте `AnketaCatalog.kt`. UI и выгрузка подхватят автоматически, потому что рендер и экспорт работают по схеме `Field`.
- **Коды полей** (`height`, `weight`, `run30`, `score` и т.д.) совпадают со строкой 1 макетных `.xlsx` из архива Kemerovo_MAOU_SOSh_36 — импорт в стороннюю систему без перекодировки.

## Следующие шаги

1. **Синхронизация через сервер**. Сейчас данные локальные + обмен файлом. Для больших школ разумно поднять backend (Supabase быстрее, свой сервер РФ — надёжнее для персональных данных школьников). Тогда родитель заполняет — учитель видит сразу, без пересылки файла.
2. **Хеширование паролей** учителей (сейчас plain — для MVP; для прода — bcrypt/argon2).
3. **QR-коды** — код приглашения класса можно распечатать/показать в виде QR, родители сканируют вместо ввода.
4. **iOS** — если нужен, разумно переписать на Kotlin Multiplatform (переиспользуя `data/`, `domain/`, `export/`).
5. **Push-напоминания** родителям («до окончания сбора 3 дня, осталось 2 анкеты»).

## Изменения в v0.3

- **QR-код приглашения**: в кабинете учителя (реестр класса) кнопка «Показать QR-код» — родители сканируют вместо ручного ввода кода.
- **Сводный PDF по классу**: кто из учеников какие анкеты сдал — на экране выгрузки.
- **Надёжный статус анкет**: явный флаг «финализирована» вместо строкового поля; открытие заполненной анкеты больше не сбрасывает её статус при просмотре.
- **Корректная очистка**: кнопка ↺ в форме реально удаляет ответы.
- **PDF без обрезки**: длинные значения переносятся посимвольно, не вылезают за край страницы; текст со сглаживанием.
- **Точные числа в выгрузке**: дробные нормализуются (запятая → точка) для сторонних систем.
- **Переход по полям**: кнопка «Далее» на клавиатуре двигает фокус к следующему полю.
- **Валидный XLSX**: добавлен стиль по умолчанию — Excel открывает без предупреждений.

## Проверено автотестами

- Генерация XLSX (открывается в openpyxl, экранирование спецсимволов, кириллица, лист «данные»)
- Целостность каталога 11 анкет (нет дублей кодов/опций, все CHOICE с вариантами, роли корректны)
- Merge-логика импорта (новый ребёнок, обновление без дублей, разные дети не сливаются)
- Алгоритм переноса текста PDF (включая сверхдлинные слова)
